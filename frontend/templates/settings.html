Settings

Choose the default local translation model for each language. Downloaded models are selectable. Models that are not downloaded are shown for information only and cannot be selected.

Custom Translation Endpoints
Describe any HTTP translation API as a request and response schema, then activate it for a language to get a translator button in the reader.
Manage endpoints →
Text Recognition (OCR Engine)
Choose which engine reads the text out of each bubble. PaddleOCR is the classic detect-then-read pipeline and always works. PaddleOCR-VL-1.6 is a vision-language model (GGUF via llama.cpp) — it only appears as selectable while llama-cpp-python (the gguf extra) is installed, and it needs its weights from the Setup page. Changing the engine takes effect after a restart. Text cleaning keeps using the classic detector either way.
Fonts
Optionally choose up to three symbol fallback fonts from your loaded fonts. They fill characters missing from the text font, in the order shown. You can also assign up to 25 characters to each fallback to always use that font, even when the text font contains those characters. Each character can belong to only one font. Selected fallbacks leave the text font picker. Their sizes are calibrated automatically for each text font in both the preview and exported pages. Leave all three empty to use only the built-in NotoSansSymbols2 fallback.

NotoSansSymbols2 always stays last. Keep at least one font for text. Your additional fonts stay in your fonts folder and are not bundled with Fox Reader.

Compute Devices
Pick the device each model runs on. Auto takes the GPU with the most memory, or the CPU when there is none, and is re-checked every time Fox Reader starts. A device that is not present falls back to the CPU without changing what you picked. The thread count applies to GGUF translation models, which choose their own.
API Tokens
Optional API tokens used by the corresponding translation services. Tokens are stored in settings.yaml. Saving validates each non-empty token (JPDB via ping, DeepL via usage — equivalent to the こんにちは → Hello test translation) and refuses invalid ones, so nothing invalid is ever saved. The DeepL/JPDB translator buttons in the reader only appear while their token is valid. Clearing a field removes that translator. DeepL free-plan keys end with :fx and use api-free.deepl.com; all other keys use api.deepl.com.
